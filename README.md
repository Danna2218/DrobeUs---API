# DrobeUs API

API REST para una app organizadora de estudiantes: materias, horario, apuntes, tareas, agenda y notas.

## Tecnologías
Node.js, Express, MongoDB, Mongoose

## Instalación
1. Clonar el repositorio
2. Ejecutar `npm install`
3. Crear un archivo `.env` copiando `.env.example`
4. Ejecutar `npm run dev`

La API queda en http://localhost:3000
